# v1.0.4 — 外观自定义

一句话版本：**启动器可以换主题色、面板透明度、整窗背景图和头像了；保存后立即生效，重启保留，旧配置照常读。**

## 新功能

设置页多了「外观」分组：

- **主题色**：预设色卡（跟随主题 / 经典蓝 / 紫罗兰 / 青碧 / 琥珀 / 玫红 / 草绿 / 石墨）+ 自定义取色；顶栏、按钮、高亮、滚动条与页面底色同源派生。
- **面板透明度**：20%–100%，开始页与管理页的面板、输入框、行、按钮一起跟随；顶栏与主按钮有 40% 下限，保证白字可读。
- **背景图**：可选本地图片，整窗铺满（含顶栏），背景透明度 10%–100%；不选图时保持原来的主题色淡渐变。
- **启动器头像**：只替换首页品牌区头像，非方图等比缩放，不拉伸。

## 选图限制

- 格式：PNG / JPG / JPEG / WEBP
- 大小：单张不超过 10MB
- 尺寸：不限
- 选中的图片会复制到 `userData/appearance/`，原图之后移动或删除不影响外观
- 设置面板会常驻显示这些限制；格式不支持、超过 10MB、文件不存在时在面板内红字提示

## 修复

- **同一路径换图后不刷新**：复制件文件名固定，换图后 URL 不变，React 与浏览器继续显示旧图；现在 URL 带内容版本参数（`?v=`），同一张图连续替换也会立即生效，不需要先点「清除」。
- **管理页面板不跟随透明度**：整合包 / DSH版本 / 插件 / 技能 / 预设页现在与开始页一致。
- **夜间外观标签看不清**：外观分组标签改用 muted token。
- **非方头像被拉伸**：改为等比缩放。

## 验证

- 全量测试 962 passed / 11 skipped / 1 failed；唯一失败是本机 PATH 里含 `dsh-tools` 的环境相关用例，与外观改动无关。`tsc --noEmit` 与 `npm run build` 通过。
- dev 实测：已有背景/头像时直接选新图，URL 版本与自然尺寸立即变化；保存后重载仍生效。
- 打包态：独立 user-data-dir 启动，确认 `dsh-appearance://` 在 asar 下加载背景与头像、选图限制文案与版本号渲染正常。

## 你要做什么

- 覆盖旧的便携版 exe 即可；`settings.json` 不需要手动改。
- 首次选图会在 `userData/appearance/` 下生成副本；之后可以随意移动原图。
- 便携版没有代码签名，SmartScreen 拦截时确认来源后选择「更多信息 → 仍要运行」。

## 已知限制

- 选图时就已复制覆盖副本，因此点「取消」只能回退设置，无法恢复上一张图的内容。
- 外观只作用于启动器界面，不改变 DSH 网页对话界面。
- 外观系统不依赖任何账号或登录。启动器另有 GitHub 集成（仓库同步 / 私有仓库 / GitHub API 数据源），本机构建未设置 `DSH_LAUNCHER_GITHUB_CLIENT_ID`，其浏览器（OAuth）登录不可用；当前前端没有暴露 GitHub 登录入口，因此不影响本版外观功能。要用这些 GitHub 集成时，请使用 CI 或带该环境变量的构建，或使用访问令牌。
