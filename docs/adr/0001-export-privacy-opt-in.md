# 整合包导出默认脱敏，隐私内容按勾选项带出

整合包导出过去把个人数据（API 凭据、会话历史、项目登记、附件）无条件剔除，这是「导出件可以放心发给别人」的唯一保证。但用户也需要把密钥和聊天记录搬到另一台机器上自己的包里。我们决定保留一个导出入口，在其中加两个默认不勾选的选项（附 API 密钥 / 附聊天记录），勾选即视为用户主动要带隐私，不再拆成第二个导出功能。

## Considered options

- **两个入口、两个名字**（「可分享导出」/「私人备份」）：被否，因为用户要的是"同一个导出多两个勾选项"，双入口反而让界面变复杂。
- **口令加密**：被否。维护者一人客服、用户会忘口令，"永久打不开"比"误转发"更容易发生且更难补救。
- **导入端识别标记**：被否（超出本次范围）。

## Consequences

勾选后产出的文件带 `.含隐私` 后缀，并在包内放一个醒目的警告文件——因为三个月后拿到这个 zip 的人（包括未来的机主自己）无法从内容判断里面有没有密钥。一旦这样的包被转发，泄露不可回收，所以警告文案必须说清"带出去收不回"，而不是只说"含隐私信息"。

「黑名单」的语义从"硬剔除"变成"默认不导出、可勾选带出"。任何后来想复用那份排除表的地方，都不能再假设它等于"安全"。
